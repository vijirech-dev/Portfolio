## Project structure

```

├── index.html                    # The whole website (HTML + CSS + embedded photo)
├── 404.html                      # "Page not found" page
├── .nojekyll                     # Tells GitHub Pages to serve files as-is
├── CLAUDE.md                     # Instructions for Claude when editing this site
└── README.md                     # This file
```

The site is plain HTML — no build step, no frameworks, nothing to install.

## Deployment (GitHub Pages)

GitHub Pages serves `index.html` straight from the `main` branch, and every push to `main` republishes the site automatically.

**One-time setup**

1. Push this repository to GitHub.
2. On GitHub, open **Settings → Pages**.
3. Under **Build and deployment → Source**, choose **Deploy from a branch**.
4. Set **Branch** to `main` and folder to `/ (root)`, then click **Save**.
5. Wait about a minute (progress shows in the **Actions** tab), then visit https://vijirech-dev.github.io/Portfolio/

## Preview locally

Double-click `index.html` to open it in any browser.

## Editing with Claude

This repo includes a `CLAUDE.md` file describing the site's structure, design rules and update workflow. Open the folder in Claude (Cowork or Claude Code) and ask in plain language, for example:

- "Add my new Springer paper to Key Achievements."
- "Update the experience count to 22 years."
- "Add a new FDP to Recognition & Continued Learning."

Claude will edit `index.html` following the conventions in `CLAUDE.md`. Commit and push the change, and the live site updates automatically.
